# ai-lab

English | [한국어](README.ko.md)

Useful open-source **programs, libraries and plugins** built around AI and automation, plus small **runnable demos** that make hard techniques easy to understand.
Projects that need API keys or models also ship a mock mode, so you can run them end to end offline, and every README walks you from installation to real use step by step.

## Getting started

Follow the Installation and Quick start sections of each project's README. Most need only [uv](https://docs.astral.sh/uv/) (Python), Node.js, or the Dart/Flutter SDK;
projects with a real-model mode list what else they need (for example [Ollama](https://ollama.com)) in their README.
All projects are MIT licensed. Licenses of the models and data they use are listed in each README.
